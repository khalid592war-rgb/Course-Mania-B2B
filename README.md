# Course Mania 🎓 • Multi-Bot Course Selling & Reseller Management Platform

**Course Mania** হলো একটি কেন্দ্রীয় টেলিগ্রাম মাল্টি-বট কোর্স বিক্রয় ও রিসেলার ম্যানেজমেন্ট প্ল্যাটফর্ম। এই প্ল্যাটফর্মের মাধ্যমে প্ল্যাটফর্ম ওনার (মালিক) এবং একাধিক অনুমোদিত রিসেলার একই সেন্ট্রাল কোর্স ক্যাটালগ ও ডাটাবেজ ব্যবহার করে তাদের নিজস্ব টেলিগ্রাম বটের মাধ্যমে কোর্স বিক্রি করতে পারেন।

## 📌 ১. মূল ব্যবসায়িক মডেল ও ৫০/৫০ ফাইন্যান্সিয়াল নিয়ম (Core Financial Rule)

### ক. ৫০% ওনার শেয়ার ও ৫০% রিসেলার শেয়ার
প্রতিটি কোর্স বিক্রির ক্ষেত্রে প্রদেয় টাকার ৫০% মালিকের প্রাপ্য এবং ৫০% রিসেলারের লভ্যাংশ হিসেবে গণ্য হবে।
* **উদাহরণ:** কোর্স ফি = ৳২,০০০
  * ওনার শেয়ার (৫০%) = ৳১,০০০
  * রিসেলার শেয়ার (৫০%) = ৳১,০০০

### খ. রিসেলার ক্রেডিট লিমিট (Credit Limit Formula)
মালিক প্রতিটি রিসেলারের জন্য একটি সর্বোচ্চ বকেয়া সীমা (Credit Limit) নির্ধারণ করে দেন (যেমন: ৳৫,০০০)।
* `বকেয়া (Outstanding Balance) = মোট ওনার ৫০% প্রাপ্যতা - রিসেলারের পরিশোধিত টাকা - এডজাস্টমেন্ট`
* `অবশিষ্ট ক্রেডিট (Available Credit) = max(0, ক্রেডিট লিমিট - বকেয়া)`

যদি রিসেলারের বকেয়া তার ক্রেডিট লিমিট অতিক্রম করে, তবে কাস্টমারের টাকা হারাবে না; অর্ডারটি **'paid_pending_fulfillment'** অবস্থায় জমা থাকবে এবং মালিককে টাকা পরিশোধ করে লিমিট ক্লিয়ার করা মাত্রই কোর্স এক্সেস রিলিজ হয়ে যাবে।

## 📱 ২. মোবাইল ফোন ব্যবহারকারীদের জন্য নির্দেশিকা (Android Mobile Users)

আপনার কোনো ল্যাপটপ বা কম্পিউটারের অভিজ্ঞতা না থাকলেও আপনি খুব সহজে পুরো ব্যবসাটি মোবাইল দিয়ে চালাতে পারবেন:

1. **মোবাইল ব্রাউজার (Google Chrome):**
   * সার্ভারের দেওয়া লিংকটি আপনার ফোনের ব্রাউজারে খুলুন।
   * **Super Admin Dashboard** থেকে সহজে নতুন কোর্স যুক্ত করতে পারবেন, ছবি ও বিডিটি মূল্য সেট করতে পারবেন।
   * বিকাশ বা নগদে কাস্টমারদের পাঠানো ট্রানজেকশন আইডি (TrxID) দেখে **"ভেরিফাই ও এক্সেস দিন"** বাটনে এক ট্যাপে কোর্স ডেলিভারি দিতে পারবেন।
2. **সার্ভারের ভূমিকা:**
   * আপনাকে ফোন অন রাখতে হবে না। একটি উবুন্টু VPS সার্ভার ২৪ ঘণ্টা স্বয়ংক্রিয়ভাবে ক্লাউডে রান করবে।

## 🤖 ৩. টেলিগ্রাম বট তৈরির ধাপসমূহ (BotFather Setup)

### ধাপ ১: বটের টোকেন নেওয়া
1. টেলিগ্রাম অ্যাপে গিয়ে সার্চ করুন: `@BotFather`
2. বটের চ্যাটে গিয়ে `/newbot` লিখে সেন্ড করুন।
3. বটের একটি সুন্দর নাম দিন (যেমন: `Course Mania Official`)।
4. একটি ইউজারনেম দিন যার শেষে `bot` থাকতে হবে (যেমন: `CourseManiaOfficialBot`)।
5. BotFather আপনাকে একটি গোপন **API Token** প্রদান করবে (যেমন: `7182938491:AAHk...82xY`)।

### ধাপ ২: প্ল্যাটফর্মে বট যুক্ত করা
1. এই ড্যাশবোর্ডে গিয়ে **"নতুন বট যুক্ত করুন"** বাটনে ট্যাপ করুন।
2. BotFather থেকে পাওয়া টোকেনটি পেস্ট করুন।
3. রিসেলারের নাম ও প্রাথমিক ক্রেডিট লিমিট (যেমন: ৳৫,০০০) দিয়ে সেভ করুন।
4. বট তাৎক্ষণিকভাবে সেন্ট্রাল ডাটাবেজে যুক্ত হয়ে যাবে!

## 💻 ৪. উবুন্টু VPS সার্ভারে ডেপ্লয়মেন্ট কমান্ড (Ubuntu Server Setup)

যেকোনো ক্লাউড সার্ভারে (Hetzner / DigitalOcean / AWS / Linode) উবুন্টু ২৪.০৪/২২.০৪ এ লগইন করে নিচের কমান্ডগুলো চালান:

### ধাপ ১: ডকার ইনস্টল করুন
```bash
sudo apt update && sudo apt install -y curl git docker.io docker-compose
```

### ধাপ ২: প্রজেক্ট নামিয়ে চালু করুন
```bash
git clone https://github.com/studyzonepaid/course-mania.git
cd course-mania
docker-compose up -d --build
```
সার্ভারটি পোর্ট `3000` এ রান হবে এবং Caddy স্বয়ংক্রিয়ভাবে ফ্রি SSL সার্টিফিকেট (HTTPS) সেট করে দেবে।
